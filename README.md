# AdLaunch — Ad Campaign Management

A set of HTML static pages for managing and monitoring advertising campaigns.

## Pages

| File | Description |
|---|---|
| `index.html` | Home / landing page with feature overview and key stats |
| `campaigns.html` | Campaign listing with status, budget, and channel filters |
| `campaign-detail.html` | Individual campaign view with stats, creatives, and edit form |
| `analytics.html` | Cross-campaign analytics dashboard with KPIs and breakdowns |
| `contact.html` | Contact / about page with enquiry form |
| `css/styles.css` | Shared stylesheet used by all pages |

## Getting Started

Open any HTML file directly in a browser — no build step required.

```
index.html          ← start here
campaigns.html
campaign-detail.html
analytics.html
contact.html
css/
  styles.css
```

## Features

- Responsive layout (mobile-friendly)
- Campaign status badges (Active, Paused, Draft, Ended)
- Budget progress bars
- Analytics KPI cards and tables
- Campaign creation / edit form
- Contact form
