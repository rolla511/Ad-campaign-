# A.W. Roadside Ad Campaign

This repository contains a banner ad snippet and a standalone landing page for the A.W. Roadside vehicle-buying campaign.

## Files

- `Aw-car_ad` — embeddable banner ad snippet
- `Aw-car_ad.html` — standalone landing page opened when the banner is clicked

## Deployment Notes

If you want this repository to deploy cleanly as a static site, GitHub Pages typically expects an `index.html` file at the publishing source.

### Suggested setup

- Keep `Aw-car_ad` for embedding as a banner
- Use `Aw-car_ad.html` as the destination page
- Optionally copy or rename `Aw-car_ad.html` to `index.html` if you want the site root to open the landing page directly
