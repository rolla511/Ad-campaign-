Connection help
  1. Keep runtime-database.html, runtime-database.js and runtime-database.css together.
  2. Run the separate private Node viewer service at this URL using npm run runtime:viewer. A static-only host does not provide its API.
  3. Configure the backend URL and matching backend credential on the viewer server, never in this HTML or browser.
  4. Check this private URL's runtime data service. It must return runtime JSON, not a static HTML page or a 404.
Runtime scope and retention rules

Counts reset on backend restart and cover this instance's observed, unexpired Quick User activity, not all database users or currently online people. The ordinary application can observe retained users when they return; this viewer does not query PostgreSQL. Memberships, subscriptions, payments, contact details, conversations and credentials are excluded.

Free activity lasts at most three days. After the fifth free buyer or seller lead, the response window ends after 24 hours or at the original deadline, whichever comes first. Search and refresh never extend retention. Displayed lead counts are observed matches, not a replacement for the application's authoritative quota checks.

This token-free viewer requires private hosting, a VPN or another access restriction. An unlisted public URL is not private.
