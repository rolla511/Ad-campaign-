What this confirms

A verified Live subscription payment and a verified completed transaction receipt are shown separately. Intended-merchant receipt is confirmed only when a verified Live transaction records a payee ID matching the configured platform merchant. Missing receipts or merchant IDs are not assumed to be successful payments. These fields do not certify an available PayPal balance, bank deposit or payout.

The report does not contact PayPal or refresh subscriptions. It reads evidence already stored by normal backend verification and signature-verified webhooks. Historical records may need reconciliation before they can show confirmed receipt.

Passwords, password hashes, session tokens, recovery codes, payment credentials, conversations and contact details are not returned. Never publish or embed an owner token in frontend files. A separate frontend URL alone does not protect subscriber/payment data.
